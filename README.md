## ⚙️ Tecnologias Utilizadas

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS v4 + Vanilla CSS Tokens
- **Animações**: GSAP 3 + ScrollTrigger + Lenis Smooth Scroll
- **SEO & OAB**: Schema.org estruturado (`LegalService`), robots.txt, sitemap.xml, llms.txt, Open Graph WhatsApp otimizado (<300 KB).
